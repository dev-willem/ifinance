# iFinance

Frontend do iFinance — plataforma de simulação financeira (financiamentos, renda fixa, VPL/TIR/payback).
Vue 3 · Vite · TypeScript · TailwindCSS v4.

O backend (Spring Boot) vive em um repositório separado: [dev-willem/ifinance_api](https://github.com/dev-willem/ifinance_api).

Veja [DEPLOY.md](./DEPLOY.md) para rodar localmente ou publicar em produção (Vercel).
Veja [IFINANCE.md](./IFINANCE.md) e [DATAFLOW.md](./DATAFLOW.md) para a documentação de produto e arquitetura.
